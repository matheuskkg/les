# Requisitos

Requisitos do DRS (E-commerce de Livros, LES 2026, v0.6), um arquivo por grupo. Cada arquivo traz RFs, RNFs e RNs
em tabelas e uma matriz de rastreabilidade para o código, a ser preenchida conforme a implementação avançar.

| Grupo | Prefixo | Arquivo |
|---|---|---|
| Geral | `GER` | [geral.md](geral.md) |
| Cadastro de Livros | `LIV` | [livros.md](livros.md) |
| Cadastro de Clientes | `CLI` | [clientes.md](clientes.md) |
| Gerenciar Vendas Eletrônicas | `VEN` | [vendas.md](vendas.md) |
| Controle de Estoque | `EST` | [estoque.md](estoque.md) |
| Análise | `ANA` | [analise.md](analise.md) |
| Recomendação Personalizada | `REC` | [recomendacao.md](recomendacao.md) |

IDs no formato `<TIPO>-<GRUPO>-<NNN>` (ex.: `RF-CLI-001`), numerados a partir de 001 por tipo dentro de cada grupo.
